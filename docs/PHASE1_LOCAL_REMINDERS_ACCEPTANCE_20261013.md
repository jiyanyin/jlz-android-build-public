本阶段仅在 `feature/phase1-local-alert-reliability-20261013` 相对 Stage6 Android 基线（PR #45）增量施工。**不动手机、不改电脑 Home Node、不生产部署，也不主动生成/安装中间 APK。**

## 代码与模拟器测试

- `LocalReminderDeliveryLedger`：成功通知后才写入已发标记；权限缺失、禁用 App 通知或关闭渠道、Android 系统通知调用抛异常时允许下次本地触发重试。不同发送者共享进程锁，避免并发重复。
- 充电/电量：单次放电周期依次允许40、20、10%阈值并只升级不回退；充电期间只有观测到超过40%且随后断电才重新启用下一周期；开始充电消息每次连接限一次，拒绝通知时仍可重试。
- 娱乐：累计30分钟提示、累计45分钟请求一次五分钟 APP 休息；仅娱乐 APP 窗口变化/滚动触发，电话/闹钟/系统/学习白名单不被五分钟休息门禁误锁，紧急放行可用。
- 时段与本地提醒：08:05 健康来源、18:30低步数检查均依真实来源，不伪造睡眠；天气、暗光、摇晃继续有冷却去重；Focus/Sleep 下不额外追加强行通知。
- 原来 Render 已退役。Android `NotificationAdapter` 的两个 Echo 深链接切换到 Pages 网页前端，不改变 Windows Home Node 实际 Runtime/MCP 地址。

## Codex 最终实机验收（四阶段全部完成并只装一次最终 APK 后）

1. **无通知权限**：暂时关闭世界之间系统消息通知，在满足一个未发提醒的事件时，检查不会写入成功去重标记；开启权限再触发相同事件应收到提醒。绝不声称此前失败已发。
2. **电量阈值**：优先用 Android 仪器化模拟电池广播验证40→20→10、低电量反弹、充电过40后再次掉到40、断电未到40的重置边界，不要求用户真实放电至10%。
3. **娱乐与休息**：娱乐 APP 30分钟本地提醒、45分钟五分钟休息页、紧急放行；生产设备尊重已经授权的 UsageStats/无障碍，不使用全机锁屏或系统安全锁绕过。
4. **通知互动**：顶部通知打开「回响」应加载当前网页前端（不是 Render），原本的直接回复、Android 安全页降级、主屏和原有消息回执不得回退。
5. 如设备通知遭到 OEM 限制，检查真实的权限/渠道/系统降级路径，不把本地 `notify()` 成功解释为用户实际看到横幅。
