## JLZ Float Timer v0.2

独立 Android 顶部悬浮计时器，用于行测/刷题。

本轮视觉改造：
- 主悬浮层完全透明，去掉白色卡片、描边与阴影
- 删除“专注 / 单题”文字标签，仅保留三行数字
- 宽度从约 205dp 收窄到约 148dp
- 数字使用 Android 系统 sans-serif-condensed 粗体，13.5sp
- 右上仅保留一个小型 ⋮ 拖动手柄
- 开始/暂停/完成按钮缩小，保留轻量半透明圆形底
- 升级时迁移旧悬浮位置，尽量保持原来的右边缘位置

功能继续保留：
- 系统时钟精确到秒
- 今日专注累计
- 单题计时与完成记录
- 今日题目历史、平均用时
- 跨 App 悬浮
- 前台服务、本地持久化、次日清零

源码快照：`JLZFloatTimer-v0.2-source.zip`

这个目录属于「世界之间」公开构建镜像里的小工具档案；不包含 Runtime、MCP、服务器、用户数据、密钥或私人历史。
