## JLZ Float Timer v0.3

独立 Android 顶部悬浮计时器，用于行测/刷题。

本轮：
- 数字切换为用户选定的 G 方案：粗体等宽 monospace 仪表风
- 修复系统字体缩放较大时三行数字与按钮互相堆叠
- 数字采用 12dp 固定视觉尺寸，不再受系统字体缩放放大
- 三行各自使用 24dp 固定高度，禁用额外 font padding
- 继续保持全透明、无白框、窄版悬浮
- 秒数跳动时数字宽度稳定，不左右晃

源码快照：`JLZFloatTimer-v0.3-source.zip`

这个目录属于「世界之间」公开构建镜像里的小工具档案；不包含 Runtime、MCP、服务器、用户数据、密钥或私人历史。
