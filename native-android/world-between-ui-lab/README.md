# 世界之间 V2 · 独立 UI 实验 APK（2026-09-29）

**应用 ID**：\`dev.jlz.worldbetween.uilab\`，不会覆盖正式客户端 \`dev.jlz.presence\`。测试包未请求网络、通知、无障碍、截屏或其他手机管理权限。

**启动页**：\`src/main/assets/index_v3.html\`。本次为独立的视觉与交互测试（P1），并非生产功能整合（P2）。保留旧版 \`index.html\` 方便比对回退。

## 本轮视觉 / 可点击交互

- 冰晶玻璃首页：本地真实时间与日期；天气明确标记「未接入」；人物区、纪临洲状态、当前安排。
- 固定首页学习入口仅 **伴读、粉笔**。点击会显示待接线说明，不假装已经打开第三方应用。
- **状态灯** 半屏：多选心情、身体状态、希望如何回应；允许一段文字。数据只加到临时预览列表。
- **记一下** 半屏：多组日常动作，瞬时事件或需要结束的计时事件；不持久化，不上传。
- **回声**：左右头像与时间戳的聊天页面，文字发送 / 拍一拍 / 演示回复。真实官端 GPT 没有收到或发送其中的文字，状态写明「本地演示」。
- **专注**：模拟的顶部胶囊计时（只在本测试 APP 可见，不会盖在粉笔 / 伴读上）；可结束并回写临时记录。
- **共历、睡眠**：有导航入口但不制造假的经期 / 睡眠事实。
- **纪临洲 Timeline**：首页简短摘要，点击打开半屏；示例行动均标记未实发。
- **来电**：从设置页「模拟来电界面」预览 UI，不是真实来电。
- **设置**：调节玻璃透明度、圆角和模糊，仅影响当前页面。

## 字体授权
CI 在编译阶段从以下开源字体工程下载，基于当前 UI 固定字符集生成 WOFF2 子集并打入 APK：
- LXGW WenKai Screen v1.522：SIL OFL 1.1，标题使用。
- Adobe Source Han Sans CN Regular (source-han-sans \`a4f7cf94edfb9d7ffbdfc4841de276358bd7e0f2\`)：SIL OFL 1.1，正文使用。
- 完整授权声明随 APK 置于 \`assets/fonts/LXGW-OFL.txt\` 与 \`assets/fonts/SourceHanSans-LICENSE.txt\`。
- **仅对子集包含的 UI 字符保证指定字体，用户自由输入里未收录的生僻字会回退系统字体。** 真正生产发行需决定是携带完整字库还是更大的字符子集。

## 验收
1. 和正式 APP 同时安装，启动「世界之间 · UI 实验」。
2. 点状态灯 → 多选 → 提交；点记一下 → 开始走路 → 结束 → 生活轴中能看到该预览事件。
3. 点回声 → 发送测试文字 → 显示在右侧气泡，明确「本地演示未送达」。
4. 点专注 → 顶部出现胶囊 → 计时增加 → 结束；进度入本次预览列表。
5. 设置 → 来电预览、玻璃透明度调整；返回桌面滚动检查手机宽度与横屏/平板排版。
6. 真机验收前不合并 \`main\`，不更换正式 APK。灰度迁移前核对实际手机运行的版本和真正生产源码。
